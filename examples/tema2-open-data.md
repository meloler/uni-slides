Tema 2: 
Sesión 1 · Qué significa que un dato sea abierto
Pregunta de la sesión: Si una institución publica una tabla o un mapa en una web, ¿podemos reutilizarlo libremente y con qué garantías?
El encargo comienza. Lunes por la mañana: el cliente envía una captura con un gráfico y dice «con esto hacemos una campaña». El equipo necesita algo más que una imagen para comparar barrios. Esta sesión responde a la primera pregunta profesional: ¿qué material podemos usar y en qué condiciones?
1.1 Publicar, mostrar, descargar y abrir no significan lo mismo
Ver una carta de restaurante en Instagram, descargar su foto y poder editar sus precios son cosas diferentes. Con los datos ocurre algo parecido. Mostrar permite consultar; descargar permite guardar una copia; reutilizar supone darles otro uso, como crear un mapa o comparar barrios. Abrir implica permitir esa reutilización bajo condiciones abiertas y ofrecer los datos de una forma procesable. La analogía sirve para distinguir acciones, no para resolver por sí sola los derechos de una carta o de un dataset.
Situación | Qué sabemos | Qué falta comprobar
- Un dashboard muestra un gráfico: Podemos consultar una representación visual. Falta comprobar si se pueden obtener los valores, reutilizar el recurso y conocer su licencia.
- Un informe está disponible en PDF: El documento puede leerse y descargarse. Falta comprobar si permite reutilización y si los datos originales están disponibles en forma procesable.
- Un CSV se descarga sin dificultad: Los valores se pueden tratar con herramientas habituales. Falta comprobar la licencia, la procedencia, la cobertura, la calidad y el significado de las columnas.
- Una ficha incluye licencia, recursos y metadatos: Hay evidencias importantes de reutilización. Falta comprobar si la fuente responde a la pregunta y si la calidad es suficiente para el uso previsto.
Ejemplo de comunicación. Una agencia recibe una captura de un gráfico sobre asistencia a eventos. Puede describir lo que el gráfico enseña, pero no debería presentarlo como un análisis independiente si no tiene los datos, la metodología y las condiciones para reutilizar la fuente. Citar la web ayuda a identificar de dónde salió la imagen; no sustituye el permiso de uso.
-> Si pueden descargar un cartel y publicarlo en una cuenta, ¿significa que también pueden quitarle el logo, modificarlo y venderlo?
1.2 Una definición práctica de Open Data
La Open Definition describe el conocimiento abierto como aquel que cualquiera puede acceder, utilizar, modificar y compartir, con condiciones limitadas para preservar aspectos como la procedencia o la apertura. En la práctica, cuando revises un dataset, comprueba si existen permisos claros para usarlo, adaptarlo y redistribuirlo.
No hace falta memorizar una definición jurídica. Quédate con esta pregunta:
¿Otra persona podría acceder a los valores, trabajar con ellos y compartir el resultado respetando unas condiciones conocidas?
La respuesta puede ser «sí», «no» o «todavía no tengo evidencia suficiente». La tercera respuesta es importante: si una ficha no muestra una licencia o no explica sus valores, no inventes lo que falta.
Aplicado al encargo. Una tabla abierta con fechas y lugares permitiría construir una agenda accesible, un mapa para una noticia o un servicio comercial. Cobrar por ese servicio no contradice por sí mismo la apertura: el permiso debe admitir usos comerciales, aunque haya obligaciones como atribuir la fuente.
Para pensar. ¿Puede una empresa cobrar por una aplicación que usa datos abiertos gratuitos? ¿Qué valor tendría que aportar para que mereciera la pena pagar?
1.3 Cuatro comprobaciones antes de decir «es abierto»
- Legal: Licencia o condiciones de reutilización. ¿Puedo usar, adaptar y compartir estos datos? ¿Qué debo atribuir o respetar?
- Acceso: Posibilidad real de obtener los valores. ¿Hay descarga, API u otro acceso razonable? ¿Funciona el enlace?
- Técnica: Formato y posibilidad de procesar los valores. ¿Puedo filtrar y analizar los datos sin transcribir una imagen?
- Documental: Metadatos, procedencia, cobertura y explicación. ¿Sé quién publica, qué periodo cubre, qué significa cada campo y cómo se actualiza?
Estas comprobaciones responden a si el recurso se puede reutilizar con unas condiciones comprensibles. No certifican que los datos sean correctos, completos, representativos o adecuados para cualquier decisión. La calidad y la interpretación requieren una segunda revisión.
1.4 La licencia es un permiso
Una licencia comunica qué usos autoriza quien tiene los derechos y qué obligaciones asume quien reutiliza el material. Busca la licencia en la ficha del conjunto y, si es necesario, en la distribución concreta. No supongas que una licencia general del portal se aplica automáticamente a cada recurso.
- CC0: La persona creadora ofrece la obra para que se reutilice con muy pocas restricciones. Citarla sigue siendo una buena práctica. Ejemplo: La Biblioteca Nacional de España ha ofrecido imágenes de algunas obras en dominio público con CC0.
- CC BY: Puedes reutilizarla, adaptarla e incluso usarla en un proyecto comercial, pero tienes que reconocer la autoría. Ejemplo: La BNE publica un conjunto de datos de su Biblioteca Digital con CC BY 4.0.
- CC BY-SA: Puedes adaptarla, pero si compartes tu versión debes ponerle la misma licencia o una compatible. Ejemplo: Una asociación de Cádiz publica una guía de rutas culturales con CC BY-SA.
- CC BY-NC: Puedes reutilizarla y adaptarla, pero no para un uso comercial. Debes citar la autoría. Ejemplo: Una fotógrafa de Valencia comparte una imagen con CC BY-NC.
- CC BY-ND: Puedes compartir la obra tal como está y citando a la persona autora, pero no distribuir una versión adaptada. Ejemplo: Un informe sobre turismo de Galicia tiene CC BY-ND.
BY: reconocer autoría. NC: no uso comercial. ND: sin obras derivadas. SA: compartir igual.
Las licencias que prohíben usos comerciales (NC) o compartir adaptaciones (ND) no cumplen la definición estricta de apertura de Open Definition. CC BY y CC BY-SA sí permiten esos usos, con sus obligaciones. CC0 es dedicación al dominio público.
La ausencia de una etiqueta de licencia no demuestra por sí sola que cualquier uso esté prohibido. Para TFS1, escribe «no he podido comprobarlo» si falta evidencia.
Citar y tener permiso son cosas diferentes. Una cita identifica la fuente; la licencia define qué acciones permite quien tiene los derechos.
Ejemplo de atribución: Fuente: [entidad publicadora], «[título del dataset]», [versión o fecha], [enlace], licencia [nombre]. Elaboración propia a partir de los datos; se han filtrado [campos] y agrupado [periodos].
El cliente propone usar también las fotos del catálogo. Atención: el permiso sobre la tabla no tiene por qué cubrir las imágenes de fotógrafos o los carteles de artistas.
Para pensar. Una imagen indica CC BY-NC y la quieren para una campaña pagada de un festival. ¿Basta con citar a su autora? ¿Qué alternativa propondrían?
1.5 Formatos y vías de acceso: cómo obtener y trabajar con los datos
El formato indica cómo se organizan los datos; la vía de acceso, cómo los obtengo.
- CSV · formato de tabla: Archivo de texto organizado en filas y columnas. Fácil de filtrar y comparar; comprueba códigos, unidades y valores ausentes.
- JSON · formato de intercambio: Organiza campos, objetos y listas; puede representar datos semiestructurados.
- GeoJSON · formato geográfico: Combina datos descriptivos con puntos, líneas o polígonos. Útil para mapas; revisa el sistema de coordenadas.
- XLSX · hoja de cálculo: Libro de hojas, celdas y fórmulas. Celdas combinadas o pestañas pueden complicar su procesamiento.
- API · vía de acceso: Servicio para solicitar datos de forma programada; no es un formato.
- PDF o gráfico · lectura: Documento o visualización preparados para leer, a menudo no permite trabajar con los valores originales.
Una API es una vía de acceso, no un formato ni una licencia.
Para pensar: la agenda está disponible como CSV y mediante una API. El equipo quiere crear un mapa que refleje cambios y cancelaciones. ¿Qué opción elegirían y qué tendrían que verificar antes de publicar?
1.6 Un recurso puede ser abierto y seguir teniendo límites
Un dataset abierto puede incluir valores vacíos, categorías poco claras, datos desactualizados o cambios de método.
Cuando presentes una cifra, intenta separar:
- Dato publicado: el valor que aparece en la fuente.
- Cálculo propio: una operación reproducible que realizaste con los valores.
- Interpretación: el sentido que atribuyes al patrón.
- Decisión: la acción que propones a partir de esa interpretación.
1.8 TFS1
En TFS1 · ¿Es realmente abierto? eliges una ficha de un portal oficial y recoges pruebas: quién publica, qué representa, periodo, distribución, formato, licencia, metadatos, posible uso y limitación. La tarea pide distinguir la evidencia que encontraste de lo que todavía no puedes asegurar.
